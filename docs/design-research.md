## 二、共性规律（"有亮点"的博客都做对了什么）

1. **首页没有大横幅图**——antfu/diygod/leerob/overreacted 全部用「大字名字 + 一句话 + 社交图标」开场，把首屏让给"你是谁"。大横幅是传统博客（包括我们现在）的做法，恰恰是最先显得"模板味"的部分。
2. **一张真人/生活照片胜过一切装饰**——diygod 放草原挥手照，leerob 放城市插画。人比图形有温度。
3. **衬线字体或大胆的标题色当身份**——leerob 全站衬线，overreacted 用亮粉粗标题，一眼记住。
4. **分类/标签是文字链不是色块**——diygod 把"创作集(26) 新坑(6)"做成正文里的一行链接，信息密度高且安静。
5. **Bio 可切换**（leerob 的 Default/Long）——小巧思但极显个性。
6. **中文圈的"亮点"= 胶囊导航 + 轮播精选 + 悬浮助手**（zhheo），视觉热闹、交互多。

## 三、三套方案（可混搭）

### 方案 A：极简杂志风（antfu + leerob 合体）— 推荐给"内容为王"
- 首页撤掉大横幅 → 改为：大字 "Hi, DKXaiLBY" + 一句话简介 + 社交图标行 + 一张你的照片/插画
- 品牌色近乎黑白（暗色模式反白），链接用主色下划线
- 文章列表保持卡片但去掉渐变封面占位，改纯排版（日期 + 标题 + 摘要）
- 点缀：点阵背景（antfu 同款）、Bio 长短切换
- 工作量：首页重排 + 配色，约 2~3 小时

### 方案 B：个性主理人风（diygod + zhheo 合体）— 推荐给"要亮点"
- 保留横幅区但升级为**轮播精选**（自动轮播你的 4 个项目封面，点击进项目页）
- 导航改**胶囊悬浮式**（zhheo 同款圆角胶囊，吸顶）
- 首页加**分类胶囊栏**（项目/前端/后端/感悟…点击筛选）
- 配色：白底 + 黑字 + 单一亮色点缀（亮紫或橙），全站仅三色
- 侧栏加"关于我"照片卡
- 工作量：导航重做 + 首页重排 + 轮播组件，约 3~4 小时

### 方案 C：内容霓虹风（overreacted 启发）— 工作量最小
- 配色：白底黑字，标题和链接用**一个大胆的颜色**（亮粉/薄荷绿/亮紫任选）
- 文章列表改纯排版风（去掉所有封面图），只留标题 + 一句话 + 日期
- 半小时换装，气质立刻从"模板"变"个人"

## 四、可单点的"亮点功能"菜单（与方案叠加）

1. 命令面板 Ctrl+K（快速跳转文章/页面，开发者味十足）
2. 打字机已有了 → 升级为「轮播一言 + 手动切换」
3. 页脚实时状态徽章（服务器运行天数/文章数，已有数据）
4. 文章内图片点击放大（灯箱）
5. 鼠标点击特效 / 背景粒子（zhheo 同类）
6. 网站运行监控小页（在线状态、负载，你的服务器数据现成）
