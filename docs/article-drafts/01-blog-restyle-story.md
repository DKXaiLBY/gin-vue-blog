# 我花了一个星期，把别人的开源博客改成了自己的世界

故事是这样的。

9 月 28 号晚上，我在 GitHub 上点了一个 fork 按钮。

那会儿我刚上大二，前端的，会的说多不多说少不少，简历上项目那一栏空得让人心慌。我需要一个博客，但我真的不想再搭一个 Hexo 模板站了。那种站面试官一天能刷到一百个，长得全都一样，点进去三秒就关掉。

我想要的，是那种点进去会觉得「哦，这人不太一样」的站。

选型看了不少，最后落在 gin-vue-blog 上，作者 szluyu99，这里认真感谢一下。理由很实际，前台 Vue3 加 Vite，后台 naive-ui，后端 Go 加 Gin，全是我正在学、以后要拿来吃饭的东西。而且它不是一个只有壳的前台，带完整的后台管理和权限系统，正好补上我想练的那块。

动手改之前，我给自己立了两条规矩。

第一条，先跑通，再动刀。

听起来像句废话对吧，但它救过我。fork 下来的第一个 commit 不是什么炫酷功能，是修环境。上游仓库在 Windows 上有个换行符的坑，CRLF 会让构建直接挂掉，我加了个 .gitattributes 强制 LF 才算把路铺平。你可能会问，就这？就这。这东西不先清零，后面每写一步都在还债，你永远分不清报错是新代码引入的，还是环境本身在漏水。

第二条，不重写。

这里我得先替「从零重写党」说句话，自己从零撸一个，确实爽，锻炼也确实大。我认真琢磨过这条路，后来放弃的。因为想明白了一件事，从零写一个博客系统对找工作没有半点加分。面试官不缺「写过 Todo 应用」的人，缺的是能读懂别人代码、然后在别人的架构上做正确改造的人。你想想看，这玩意才是上班以后每天真正要干的活。

好了，规矩讲完，开工。

第一刀砍的是信息架构。上游的导航塞了两级下拉，什么「发现」什么「娱乐」，一大堆我用不上的页面，全砍了。首页、归档、项目、说说、简历、历程、留言，平铺，低频的收进「关于」。相册页整个下线，路由重定向到说说，少维护一个半成品。归档、分类、标签合成一个三 Tab 的档案页。页面变少了，但每一页都是真的在用的，这种感觉比页面多舒服多了。

减完肥，开始注入世界观。

我一直觉得，一个个人博客最值钱的不是功能列表，是它有没有一个统一的「世界」。我给自己定的是终端风。现在你打开我的博客，首屏是一个真的能敲的终端，敲 help 有帮助，敲 ls projects 列项目，敲 sudo hire-me，它直接把简历甩你脸上。还有 play type，一个打字测速的小游戏，手速慢的不建议点进去，容易破防。

留言板也是这个路数，每条留言长成 DKXaiLBY@blog:~$ 后面跟一句话的样子。历程页我做成了开发地铁图，十九个站点串起整个开发时间线，还标了一个「你在这」。深色模式下首页偶尔划过一颗流星，概率不高，但你刷到那次会笑出来。

世界观统一有个隐藏的好处，以后每加一个功能，不用现想它该长什么样，问一句「在终端的世界里它应该是什么样」就行了。

说真的，光有花活撑不起一个作品集，还得有点访客真的用得上的东西。

我给后端加了个状态接口，把 Go 的运行时长、内存、协程数暴露出来，在线人数用 Redis 的 ZSet 做了个五分钟滑动窗口，访客在状态页能看到这个网站自己知道自己活着。AI 助手也上了，后端先去 MySQL 里检索文章、项目、说说当上下文，再丢给大模型组织语言，接的是 OpenAI 兼容接口，配哪家模型都行，我用的智谱 glm-4-flash，免费。调用失败会自动回落到一个纯规则版的回答，不至于当场挂掉。

阅读这块也顺手打磨了一轮，图片灯箱、卡片上的阅读时长、「上次读到 65%，继续吗」这种提示条。都是小东西，但加起来，常来的访客会觉得这个站有人在乎。

然后是我最想聊的一段，翻车。

v3.42 那天我一口气做了十二项动效，主题切换的圆形扩散、卡片的聚光和 3D 倾斜、点赞粒子爆裂，做完自己看哪儿哪儿都好。冷静下来之后我干了一件事，换个身份当自己的敌人，对这十二项逐个攻击，就假设里面一定藏着 bug。

真让我抓着了。

年度报告页有个 computed 没导入，Vue3 的 setup 写法不报错、不警告，就是安静地白屏。

白屏。

我当时盯着它后背有点发凉，这要是直接上了线，访客点进去就是一片空白，我还蒙在鼓里觉得自己贼高效。。。从那以后我的流程固定了下来，大改动，自测，然后开一轮敌意审查，修完才算完。AI 帮我写代码确实快，但 bug 也是它埋的，审查这一步，没人能替你省。

写到这儿，盘个账。

七天。五十个 commit。八个版本 tag，每个稳定点都能一键回滚。前台三十二个测试文件、两百零七条用例全绿，lint 干净。线上四个 Docker 容器，nginx、Go、MySQL、Redis，在一台 1.6G 内存的小服务器上转着。部署和运维的细节挺多的，我单独写了一篇，感兴趣的可以翻。

最后说点数字之外的。

这事做到一半我突然意识到，开源这玩意挺浪漫的。szluyu99 把他的项目开源出来，我 fork 下来，改成了我的世界。说不定哪天也有个大学生，在某个晚上点下 fork 我的仓库的按钮，从这里开始折腾他自己的东西。一棒接一棒，代码就是这么传下去的。

而对我来说，七天前那个空得发慌的简历项目栏，现在是一个能敲命令、会掉流星、有留言墙、跑在真实服务器上的活网站。

那个 fork 按钮，是我这学期按过最值的一下。
