# 我把自己的博客玩坏的八次

说实话，写这种排障笔记我心里一直是打鼓的。

因为八个坑全是我自己踩的，聪明人看完可能会说，这些坑压根就不该踩。但你先别急，等我讲完你会发现一件事，它们没有一个是知识不够造成的，几乎全是工具和环境在说谎。lint 说它改得更规范了，netstat 说端口空着，dump 文件说它会恢复到指定的库。

过去一个星期，我的博客项目唯一的报障用户，是我自己。

一个一个讲。

1、eslint --fix 之后，测试全军覆没。

有次跑完 eslint --fix，整个 Vitest 套件直接爆炸，报错指向一张 PNG 图片，说 file:///xxx.png 不是合法模块。我第一反应是测试配置坏了，查了半天 vitest。真相是 vue/no-useless-v-bind 这条规则「好心」把模板里的 :src="'/img/x.png'" 字面量绑定改回了静态 src，而 Vue 编译器会把静态资源 src 编译成模块导入，图片在测试环境当然没法当模块解析。

好心办坏事。

它真的认为自己在修代码，还修了个 bug 进去。现在我项目里 public 资源一律写成 script 常量再绑定，并且 --fix 之后必跑全量测试。工具的「自动修复」，也得过测试这一关。

2、动画卡死，其实是页面在后台。

做自动化验收的时候，离开动画永远停在第一帧，Transition 像死了一样。我盯着组件逻辑看了很久，越看越觉得代码没问题。代码确实没问题，问题是浏览器会对被遮挡的后台标签页做 requestAnimationFrame 节流，Vue 的 Transition 靠 rAF 驱动，标签页不在前台，动画就整个冻住。更诡异的是那种环境里连 setTimeout 都可能被钳到一秒以上，你写个延时五百毫秒的断言能等到天荒地老。这个坑教会我的事，先确认测量环境有没有在骗你，再怀疑代码。

3、漏 import 一个 computed，页面安静地消失。

年度报告页整页白屏，控制台干干净净，零报错，是我最怕的那种安静。查路由、查异步组件，全正常。最后定位到的是一个反常点，页面里排在它后面的兄弟组件渲染得好好的，说明路由没毛病，是这个组件自己在 setup 阶段就断了。原因特别蠢，<script setup> 里用了 computed 但忘了 import，Vue3 不报错不警告，组件就是不渲染。更羞耻的是，后来一轮敌意审查又抓到一个同款，我给它标了 P0。这个坑见一次就得防一辈子，新组件写完本地跑一遍，没有例外。

4、一个换行符，后端循环重启。

有天晚上给配置文件追加一段 AI 配置，上传重启，后端容器开始循环崩溃。缩进没问题，字段名也没问题，最后发现是原文件最后一行结尾没有换行符，追加内容焊在了上一行后面，YAML 解析当场去世。这事我在部署那篇里详细写过，这里只补一句，改配置文件要盯的不只是内容，还有那些看不见的字符。

5、恢复备份，差点把正式库覆盖了。

想把一份 mysqldump 灌进「临时库」做演练，操作完发现正式库数据不对劲。真相是 dump 文件头部自带 CREATE DATABASE 和 USE 语句，恢复到哪个库由它自己说了算，我指定的库从头到尾没参与过。整个过程最吓人的是中间那几分钟，我一度以为正式数据没了。顺手还学到一件事，验证数据时客户端得带 utf8mb4，不然中文显示乱码只是显示问题，HEX 一查字节是对的，差点手一抖重导一遍把好数据冲了。备份的价值等于你演练过的那次恢复，但演练也得系安全绳。

6、全站导航点不动，凶手是一个没加引号的选择器。

有个用户报障，说点导航偶尔卡在「加载中」，刷新又一切正常。时好时坏，最烦人的一种。这个用户是谁我就不说了，反正他当天挺沮丧的。我一开始怀疑路由懒加载的 chunk 挂了，方向完全错了。真凶是 router.afterEach 里一段设置 SEO meta 的代码，选择器字符串拼成了 meta[og:title]，属性值没加引号，querySelector 直接抛语法错误，把整条导航守卫链炸断。刷新为什么又好了，因为刷新走的首次渲染路径根本不经过那段代码。

这篇我最想让你带走的就是排查它的方法。这类 SPA 故障整页刷新是复现不了的，刷新会丢掉全部错误现场，你得先在首页注入 window.onerror 和 unhandledrejection 钩子，再用 router.push 在站内做导航，错误才会现形。SPA 的 bug，要在 SPA 里抓。

7、深链进入的页面，数据不加载。

分享出去的 /archives?tab=tags，进去后 Tab 高亮是对的，内容是空的，站内点击切换又一切正常。我以为是接口挂了。真相特别典型，Tab 切换靠 watch 拉数据，而 watch 只响应变化，不负责初次。深链进入时参数在初始化时就赋好值了，永远触发不了回调。修复是在 onMounted 里按当前 Tab 主动拉一次。写这类页面的时候多问自己一句，直接带着参数进来的人，数据从哪来。

8、端口明明空着，dev server 起不来。

Windows 特供。Vite 报 EACCES，netstat 查了端口明明没人占用，系统说没人占用，端口也说没人占用，就是绑不上，换一个端口还是报。= = 这个锅是 Windows 的排除端口范围，系统保留的一段端口，查不到占用，也绑不上去，纯黑名单。netsh interface ipv4 show excludedportrange protocol=tcp 能看到名单，绕开就行。在 Windows 上开发的同学记住这条，报 EACCES 别死磕 netstat。

八个讲完了。

写完这八条，我突然想起福尔摩斯那句被我刻在脑子里的名言，当你排除了一切不可能，剩下的不管多么匪夷所思，那都是真相。这一周我对它的理解加深了一层，在开发的场景里，那些「不可能」经常改头换面，变成「工具说它好了」「环境说它没事」，而你要做的，就是不信。

所以我现在的排障三板斧，先怀疑测量环境，再找反常证据，最后才有资格怀疑框架。顺序反了的话，你会在正确的代码里耗一整晚。

这三板斧不一定对，我自己也还在摸索，但它这周实实在在让我少熬了几个通宵。
