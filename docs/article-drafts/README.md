## 当前版相对上一版补了什么

- 口语词组密度提到每篇 10 个上下（对吧就这、你敢信？？？、我认了、白捡、纯黑名单这类）
- 每篇加了「对立面的理解」段，先替对方把话说完再给观点（重写党、CI/CD 派、聪明人视角）
- 加了疑问句刹车（容器明明起来了为啥还要 TCP 戳它）和断裂句（白屏。／一个换行符。／好心办坏事。）
- 文化升维补齐，02 借了民航复盘文化，03 借了福尔摩斯那句名言
- 03 按方法论文章规范加了谦逊铺垫（写这种笔记我心里一直打鼓）和坦诚的学习曲线
- 四层自检 L1 全绿（禁用词、冒号、破折号、双引号零命中），L2 情绪标点三篇各至少一处

## 这版改了什么（相对被打回的初稿）

- 正文去掉了全部 markdown 小标题、表格、bullet 罗列，纯散文短段落
- 删掉了「综上所述」类总结腔和排比句，改为口语节奏（长短句交替、一句话独立成段）
- 标点遵守规则，正文无冒号、无破折号、无双引号（引号用「」）
- 每篇开头从具体事件切入，结尾回扣开头，不再用「三条心得」式收束

## 发布建议

1. 别一次全发，隔 2~3 天发一篇（01 → 02 → 03）。
2. 每篇文件开头有一段「发布信息」，是给后台填表用的，标题 / 摘要 / 分类 / 标签 / 封面建议，正文从一级标题开始复制。
3. 发之前务必通读一遍，用自己的口吻顺一遍。特别注意，文中的情绪和体感描写（愣住、后背发凉、盯着看了一分钟）是按真实事件合理还原的，**哪里跟你当时实际感受不符，改成你自己的**，这是活人感最重要的一层。
4. 检查点，文中刻意没写服务器 IP、QQ 号、任何密钥，保持住，配图里也别露；截图裁掉浏览器书签栏；发布时的数字（测试数、commit 数）如果变了随手更新。
